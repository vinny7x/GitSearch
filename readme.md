# GitSearch

## 🔍 Ferramenta para busca de perfis do GitHub

### Descrição

O **GitSearch** é uma aplicação web desenvolvida como parte de uma atividade do curso **Full Stack Developer da +praTI**. O projeto permite pesquisar usuários do GitHub e exibir informações públicas do perfil, como avatar, biografia, localização, quantidade de seguidores, repositórios e outros dados disponibilizados pela API do GitHub.

### Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript
- GitHub Users API

### API utilizada

Este projeto utiliza a **GitHub REST API** para obter informações públicas de usuários.

📖 Documentação oficial: https://docs.github.com/pt/rest/users/users
